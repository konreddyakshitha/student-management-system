# Student Management System

## Project Description

The Student Management System is a Python-based application that allows users to manage student records using a SQLite database.

The application provides a simple menu-driven interface for adding, viewing, searching, updating, and deleting student information.

## Features

- Add new students
- View all students
- Search students by ID
- Update student information
- Delete student records
- Validate student names and ages
- Prevent duplicate student IDs
- Store data permanently using SQLite
- Menu-driven interface

## Technologies Used

- Python
- SQLite
- SQL
- VS Code

## Database

The project uses SQLite to store student information.

The database contains the following fields:

- Student ID
- Student Name
- Student Age
